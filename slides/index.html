AE 的問題：潛在空間沒有被組織

每張訓練圖都對應一個點（黑點）。點與點之間的空白，沒有任何約束。

點擊畫布任一位置，判斷此處的解碼結果是否有意義。

為什麼 AE 的潛在空間會「壞掉」？

  • 目標只有「重建得好」：AE 的損失只要求 x̂ ≈ x，沒有說 z 應該長什麼樣子。
  • 點的位置是任意的：不同圖的 z 可能擠在角落，中間留下大片空白。
  • 鄰近的點不一定語意相近：兩個點之間插值，可能落在空白區，解碼得到雜訊或怪圖。
  • 我們不知道 z 的分布：沒有 p(z)，就無法有意義地「隨機取樣」去生成新資料。

結論：AE 是壓縮工具，不是生成模型。

VAE 的核心想法：把「一個點」換成「一團雲」

  • 編碼器不再輸出一個點，而是輸出一個高斯分布的參數：均值 μ 與變異數 σ²
  • 訓練時，從 N(μ, σ²) 取樣得到 z，再送進解碼器
  • KL 散度把每團雲拉向標準常態 N(0, I)
  • 雲與雲互相重疊 → 潛在空間變得連續，取樣有意義

下一頁的動畫中，點會從 AE 狀態「變形」成 VAE 的雲。

從 AE 到 VAE：潛在空間的變化

VAE 狀態下，雲與雲重疊，隨機取樣落在「有資料覆蓋」區域的機會明顯提高（上例約 2 倍）。

編碼器：輸入與輸出

內容維度（MNIST 例）
輸入一張影像 x28×28 → 784 維向量
輸出 1均值 μ(x)d 維（例如 d = 2）
輸出 2對數變異數 log σ²(x)d 維

$$z=\mu(x)+\sigma(x)\odot\varepsilon,\qquad \varepsilon\sim\mathcal N(0,I)$$

實作上輸出 log σ² 而非 σ²：這樣 σ² 一定為正，數值也較穩定。

幾何意義：輸入的每張圖，在潛在空間中對應一個橢圓形的高斯分布。

解碼器：輸入與輸出

內容說明
輸入潛在變數 z ∈ ℝd從 q(z|x) 取樣而來
輸出影像 x̂ = g(z)是 p(x|z) 的平均值

$$p_\theta(x\mid z)=\mathcal N\big(x;\ \hat x(z),\ \sigma_x^2 I\big)$$

幾何意義：解碼器的每個輸出不是一張圖，而是影像空間中的一團分布，中心在 x̂(z)，半徑由 σx 決定。

（若假設高斯似然，最大化 log p(x|z) 就等價於最小化 MSE，理論篇會說明。）

中間層的 z 還是一個向量嗎？

自編碼器 AE

z 是確定性的：同一張圖，每次都得到同一個 z。

z = f(x)

變分自編碼器 VAE

z 是隨機變數：同一張圖，每次取樣得到不同的 z。

編碼器真正輸出的是 μ(x), σ(x)；z 是從分布抽出的一個樣本。

所以 z 仍是一個 d 維向量，但它的來源已經從「算出來」變成「抽出來」。

Part II

理論

生成模型的目標

假設資料由潛在變數產生：

$$z\sim p(z)=\mathcal N(0,I),\qquad x\sim p_\theta(x\mid z)$$

目標：最大化資料的邊際似然 log pθ(x)

$$p_\theta(x)=\int p_\theta(x\mid z)\,p(z)\,dz$$

困難：這個積分要對所有可能的 z 積分，在高維度中無法計算。

解法：引入一個近似後驗 qφ(z|x)，也就是編碼器，用變分推論來逼近。

ELBO：證據下界

$$\log p_\theta(x)=\text{ELBO}\;+\;D_{KL}\big(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\big)$$

$$\text{ELBO}=\mathbb E_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]-D_{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)$$

  • 最後一項 DKL(q ‖ p(z|x)) 永遠 ≥ 0
  • 因此 log p(x) ≥ ELBO，ELBO 是 log 證據（evidence）的下界
  • 等號成立 ⇔ q(z|x) = p(z|x)，即編碼器完美地逼近真實後驗

ELBO 在 VAE 中的作用

  • 我們無法直接算 log p(x)，但可以算 ELBO
  • 最大化 ELBO 會同時做兩件事：
    1. 把 log p(x) 推大（模型解釋資料的能力變好）
    2. 把 q(z|x) 拉向真實後驗（縮小下界與真值的差距）
  • 訓練時對整個資料集最大化 ELBO，實務上用小批次隨機梯度與單一樣本估計期望值

名稱中的 Evidence = log p(x)，指的是「資料的對數似然」；Lower Bound 指它是真值的下界。

損失函數：重建 + KL

$$\mathcal L(x)=\underbrace{-\,\mathbb E_{q_\phi(z|x)}\!\big[\log p_\theta(x\mid z)\big]}_{\text{重建項}}\;+\;\underbrace{D_{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{正則項（KL）}}\;=\;-\text{ELBO}$$

  • 重建項：解碼器能不能把 z 還原成 x
  • KL 項：編碼器輸出的分布要不要貼近先驗 N(0, I)
  • 最小化 𝓛 ＝ 最大化 ELBO

重建項為什麼是 MSE？

假設解碼器輸出高斯分布：

$$-\log \mathcal N(x;\hat x,\sigma_x^2 I)=\frac{1}{2\sigma_x^2}\,\lVert x-\hat x\rVert^2+\text{const}$$

  • 因此重建項 ∝ MSE（像素差的平方和）
  • σx 固定時，它只決定 MSE 的權重
  • 實務上常寫成：𝓛 = MSE + β · KL（β 為權重，β-VAE 的想法）

MSE 與 KL 的相對大小很重要：權重不同，模型會偏向「重建得準」或「潛在空間整齊」。

KL 散度：閉式解

當 q(z|x) = N(μ, diag(σ²))、p(z) = N(0, I) 時，KL 有解析解：

$$D_{KL}=-\frac12\sum_{j=1}^{d}\Big(1+\log\sigma_j^2-\mu_j^2-\sigma_j^2\Big)$$

  • 逐維度看：½(μ² + σ² − 1 − log σ²)
  • KL ≥ 0，且等於 0 的唯一條件是 μ = 0、σ = 1
  • 因為是閉式解，訓練時不需要用取樣去估計 KL

KL 的幾何意義：把雲拉回原點

拖動 μ 與 σ：橘色為 N(μ, σ²)，灰色為先驗 N(0, 1)。

μ² 項：均值離原點越遠，懲罰越大 → 雲不會飛走

σ² − log σ² − 1 項：σ 趨近 0 會被大力懲罰，太大也會懲罰 → 雲保持適中大小

重建與 KL 的拉扯

重建項想要

  • σ 小：定位精確
  • 不同圖的 μ 分開：可區分

KL 項想要

  • σ ≈ 1：雲有適中大小
  • μ ≈ 0：雲集中在原點附近

平衡後：雲有一定大小、彼此重疊，且仍保有資訊 → 連續、可取樣。

只有重建

σ → 0，雲退化成點，變回 AE，潛在空間出現空洞。

只有 KL

所有雲都變成 N(0, I)，z 不含任何資訊（後驗崩潰，posterior collapse），解碼結果都是同一張平均圖。

動畫：KL 與重建的拉扯（Manim）

重建想讓雲縮小、分開；KL 想讓雲變大、靠攏。兩者的平衡決定了潛在空間的樣子。

重參數化技巧：問題在哪？

訓練需要對 ELBO 的期望值求梯度，而期望值中包含一個抽樣動作：

$$z\sim\mathcal N(\mu_\phi(x),\sigma_\phi^2(x))$$

  • 「抽樣」是隨機節點，梯度無法穿過它
  • 因此 loss 無法反傳到 μ, σ，編碼器學不到東西

我們需要一個「能反傳」的寫法，同時保持 z 的分布不變。

重參數化技巧：把隨機性移走

$$z=\mu+\sigma\odot\varepsilon,\qquad \varepsilon\sim\mathcal N(0,I)$$

隨機性只在 ε 上（不含參數）→ 給定 ε 後，z 是 μ、σ 的確定函數，梯度可以反傳：\(\frac{\partial z}{\partial\mu}=1,\ \frac{\partial z}{\partial\sigma}=\varepsilon\)

左：固定的標準常態樣本 ε；右：z = μ + σ⊙ε。移動 μ、σ 時，ε 不變。

完整的 VAE 訓練步驟

  1. 取一個 mini-batch 的 x
  2. 編碼器輸出 μ(x), log σ²(x)
  3. 取 ε ~ N(0, I)，計算 z = μ + σ⊙ε（重參數化）
  4. 解碼器輸出 x̂ = g(z)
  5. 損失 = 重建項（MSE）+ β · KL（閉式解）
  6. 反向傳播，同時更新 φ（編碼器）與 θ（解碼器）
mu, logvar = encoder(x)
std = torch.exp(0.5 * logvar)
eps = torch.randn_like(std)
z = mu + std * eps                  # 重參數化
x_hat = decoder(z)

recon = F.mse_loss(x_hat, x, reduction='sum')
kl = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
loss = recon + beta * kl

生成新資料時：z ~ N(0, I) → 解碼器 → x̂。因為 KL 讓所有雲貼近 N(0, I)，這樣取樣是有意義的。

動畫：為什麼從先驗取樣能生成？（Manim）

訓練後，編碼器的雲填滿了先驗 N(0, I) 的主要區域；從先驗取樣，就會落在有意義的位置。

總結

  • AE → VAE：從「點」變成「分布」，潛在空間變得連續
  • 編碼器：影像 → 潛在分布（μ, σ）；解碼器：潛在點 z → 影像分布（x̂）
  • 損失：重建（MSE）+ KL，來自 ELBO 的負值
  • KL：把雲拉向 N(0, I)，防止退化，讓取樣有意義
  • 重參數化：z = μ + σ⊙ε，讓梯度穿過隨機節點

延伸：β-VAE（解開的表示）、條件式 VAE（CVAE）、VQ-VAE、與擴散模型的關係。
